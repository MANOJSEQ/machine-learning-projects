# Multiple Linear Regression

A machine learning project that predicts startup profit based on R&D Spend, Administration Spend, Marketing Spend, and State using Multiple Linear Regression.

## What I Did

* Imported and explored the dataset
* Separated independent and dependent variables
* Encoded the categorical State column using One-Hot Encoding
* Split the data into training and test sets
* Trained a Multiple Linear Regression model
* Predicted startup profit values
* Compared predicted profit with actual profit

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
