# Simple Linear Regression

A machine learning project that predicts salary based on years of experience using Simple Linear Regression.

## What I Did

- Imported and prepared the dataset
- Split the data into training and test sets
- Trained a Simple Linear Regression model
- Predicted salary values
- Visualised the results using graphs

## Skills Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
